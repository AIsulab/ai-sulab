# SULAB 포트폴리오 웹사이트

AI 기술로 홈페이지 제작과 마케팅 자동화를 수행하는 브랜드 **SULAB**의 공식 포트폴리오 웹사이트입니다.

## 🌟 프로젝트 특징

- **디자인 스타일**: DesignPixel 스타일의 프리미엄 인터랙티브 웹사이트
- **수평 슬라이드 전환**: 메인 페이지에서 오른쪽→왼쪽 슬라이드 효과
- **자동 슬라이드**: 6초 간격의 자동 슬라이드 및 무한 루프
- **반응형 디자인**: 12-column 그리드 시스템을 활용한 완벽한 반응형
- **Hash 라우팅**: SPA 방식의 해시 기반 페이지 라우팅

## 🛠️ 기술 스택

- **React** - UI 라이브러리
- **Vite** - 빠른 개발 환경
- **TypeScript** - 타입 안정성
- **Tailwind CSS v4** - 유틸리티 우선 스타일링
- **Motion** (Framer Motion) - 부드러운 애니메이션

## 📄 페이지 구성

### 메인 페이지
- 수평 슬라이드 레이아웃
- 자동 전환 및 휠 스크롤 인터랙션
- 프로젝트별 카테고리 슬라이드

### 서브 페이지
1. **Home** - 메인 인터랙티브 슬라이드
2. **Overview** - 회사 소개 및 비전
3. **Portfolio** - 웹 프로젝트 포트폴리오
4. **Design Works** - 디자인 작업물 갤러리 (NEW!)
5. **Mobile** - 모바일 앱 프로젝트
6. **CI/BI** - 브랜드 아이덴티티 작업
7. **Request** - 프로젝트 의뢰 폼
8. **Contact** - 문의하기
9. **Notice** - 공지사항 (페이지네이션 포함)

## 🎨 디자인 포트폴리오 갤러리

새롭게 추가된 **Design Works** 페이지는 다음 기능을 제공합니다:

- **썸네일 그리드 뷰**: 작업물을 카드 형식으로 시각적 표시
- **카테고리 필터**: UI/UX, Branding, Web Design, Graphic Design, Marketing, Illustration
- **실시간 검색**: 제목, 설명, 태그로 작업물 검색
- **라이트박스 모달**: 작업물 클릭 시 상세 정보 확대 보기
- **애니메이션**: 부드러운 전환 효과와 인터랙션

## 🚀 시작하기

### 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm run dev
```

### 빌드
```bash
npm run build
```

### 프로덕션 미리보기
```bash
npm run preview
```
